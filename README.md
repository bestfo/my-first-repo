# 채팅방 메이커

홍보 영상용 메신저 채팅방 화면을 만드는 도구입니다. PC 카톡(창) 스타일과 모바일 스타일을 고를 수 있어요. `chat-maker/index.html`을 브라우저(크롬 권장)로 열면 바로 쓸 수 있어요. 설치는 필요 없습니다.

- 참여자 추가, 이름·프로필 사진 설정, ‘나’ 지정(오른쪽 노란 말풍선)
- 사람별로 대화 직접 입력(텍스트·사진·이모티콘·날짜 구분선·안내 문구), 시간·안읽음 숫자 편집, 순서 변경
- 녹화 모드: Space/→ 다음 메시지, ← 이전, A 자동재생, R 처음으로, P 현재 화면 PNG 저장, Esc 나가기
- PC 스타일: 말풍선 옆 공유(↳) 버튼, 오른쪽 아래 ↓ 버튼 표시 가능
- [PNG 저장]으로 지금 화면을 1~3배 크기 이미지로 저장
- 작업 내용은 브라우저에 자동 저장되고, [저장(JSON)]으로 파일로 받아 둘 수 있습니다
